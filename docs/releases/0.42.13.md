# Boolka 0.42.13

Изменения с 0.42.1:

- Компактный список с иконками, авторами, категориями и количеством скачиваний. При обновлении видны установленная и новая версии. Плитки и настройка изображений удалены.
- Единые цвета состояний для трёх тем, квадратные углы, улучшены заголовок и кнопки боковой панели.
- В импорте и экспорте аддоны разделены карточками. В импорте можно выбрать нужные аддоны; повтор после частичной установки показывает оставшиеся.
- Окно удаления уменьшено, длинный список прокручивается. Настройки стали компактнее.
- Запись цен и других рабочих файлов аддонов больше не подсвечивает проверку обновлений. Учитываются манифесты и изменения состава папок.

Windows x64. Скачайте ZIP, распакуйте всю папку и запустите `boolka.exe`. Закройте ESO перед изменением аддонов.
