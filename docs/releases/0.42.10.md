# Boolka 0.42.10

- Плитки квадратные и подстраиваются под ширину и число колонок.
- Изображение заполняет карточку без искажения пропорций, с обрезкой краёв.
- На нижней подложке — название и только доступная кнопка «Установить»/«Обновить». Для уже установленных проектов неактивной кнопки нет.
- Статистика, версии и предупреждения доступны в подсказке, проблема библиотек дополнительно отмечена знаком внимания.
- Кнопка остаётся внутри карточки; сохранены виртуализация и корректная прокрутка при смене числа колонок.

Windows x64, папка с файлами без ZIP. Запуск — boolka.exe.
