# Boolka 0.42.5

- Единая палитра состояний для Dracula, тёмной и светлой тем.
- Обновления — зелёные, предупреждения — жёлтые, ошибки — розовые. Выбор и прогресс — акцентным цветом темы; подтверждение удаления — красное.
- Подсветка всей кнопки, контрастный текст, нейтральные обычные и неактивные состояния.
- Статусы аддонов отделены от кнопок действий; предупреждения о библиотеках видны в компактном списке.
- Скачивание показывает процент при известном размере; квадратные углы сохранены.

Локальная сборка Windows x64 предоставляется распакованной папкой без ZIP. Запуск — boolka.exe.
