# Boolka 0.42.7

- Хлеб перенесён к верхнему названию Boolka в заголовке окна.
- Запуск: нейтральная кнопка «Запустить ESO» с зелёным значком; во время запуска — «Запускаем…».
- Более компактный список: превью 44px, название и автор в одной строке, категория под названием. Справа — скачивания, версия/сравнение версий и действие либо спокойный статус установленного аддона.
- Обычная строка списка занимает около 60px; предупреждения о библиотеках не обрезаются.

Локальная сборка Windows x64 — папка с файлами, без ZIP. Запуск — boolka.exe.
