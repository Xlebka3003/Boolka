# Boolka 0.42.11

- Удалены плитки и переключатель вида: остаётся один виртуализированный список.
- В списке используются только локальные иконки категорий. Загрузка превью для списка удалена.
- В настройках больше нет пункта «Изображения модов».
- PreviewMode, CompactRows и TileColumns исключены из схемы настроек. Старые поля игнорируются и удаляются при первом запуске новой версии; остальные параметры сохраняются.
- Масштаб списка и прежние функции установки, обновления, импорта/экспорта сохранены.

Windows x64, распакованная папка без ZIP. Запуск — boolka.exe.
