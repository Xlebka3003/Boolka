# Boolka 0.42.2

- Аддоны в окне импорта разделены карточками с отступами и рамками.
- Добавлены галочки и выбор всех аддонов. Изменённый состав и необходимые библиотеки проверяются перед окончательным согласованием.
- При повторе после частичной установки показываются только оставшиеся аддоны.
- Видимое название приложения — Boolka.

Windows x64. Распакуйте весь ZIP и запустите boolka.exe. Закройте ESO перед изменением аддонов.
