# Boolka 0.42.14

Исправлена проверка адресов обновления после смены регистра названия репозитория на Boolka. Ссылки проекта обновлены. Имена EXE и архивов сохранены для совместимости.

Версии до 0.42.14 требуют однократного ручного обновления: они сравнивают адрес архива с прежним регистром имени репозитория.
