# Стиль Boolka

Три темы: Dracula, тёмная и светлая. Все углы квадратные. Доступен только список с локальными иконками категорий.

| Состояние | Цвет | Использование |
|---|---|---|
| Выбор и прогресс | Фиолетовый в Dracula, синий в остальных темах | Выбранная строка, вкладка, галочки, скачивание и установка |
| Доступно обновление | Зелёный | Статус аддона, кнопки обновления аддонов и приложения |
| Требуется внимание | Жёлтый / тёмный жёлтый на светлом фоне | Недостающие библиотеки, изменённая папка, предупреждения |
| Ошибка | Розовый | Ошибки операции и некорректные данные |
| Опасное действие | Красный | Подтверждение удаления |
| Обычное состояние | Нейтральный | Установленные аддоны, метаданные, обычные кнопки |

Цвет дополняет текст, а не заменяет его. Статус установленного аддона отделён от кнопки действия. Неактуальная подсветка снимается после проверки; незавершённая операция показывает прогресс. Нижний статус доступен для копирования.

Кнопка состояния использует полную заливку и рамку с контрастным текстом; наведение не меняет смысл цвета. Выбор строки — акцентная рамка и спокойный фон, без окрашивания всей строки в цвет проблемы.

Общие цвета определены в ThemePalette, WPF-ресурсы — State.* в ThemeManager. Для кнопок используются ButtonState.Apply и ButtonState.Select. Радиусы всегда нулевые. Новые экраны должны использовать эти ресурсы вместо отдельных подобранных цветов.

Скрытая проверка: `dotnet build tests/UiStates/UiStates.csproj -m:1`, затем `dotnet tests/UiStates/bin/Debug/net8.0-windows/UiStates.dll` из корня проекта. Проверяется контраст не менее 4.5:1 для текста на цветных кнопках, реальные шаблоны, сброс состояний, прогресс и три темы. Приложение, игра и видимые окна не запускаются.

Список аддонов: превью 44px, название и автор в одной строке, категория ниже; справа скачивания, версия/сравнение и действие. Обычная строка около 60px, предупреждения могут увеличивать высоту. Значок запуска ▶ зелёный при нейтральном фоне кнопки; это отдельное согласованное исключение для узнаваемого действия запуска игры. Хлеб расположен в верхнем заголовке окна, рядом с верхней Boolka.

Разделитель между сведениями — ` | `, между версиями — `→`. Верхние хлеб и название находятся внутри фоновой области заголовка и должны полностью помещаться при масштабе 0.85 со свёрнутой панелью. Блок папки компактный, но полный путь сохраняет перенос.
Значки запуска игры и поддержки — залитые силуэты; остальные значки остаются контурными. Цвет запуска зелёный, сердечка — акцент темы.


Режим плиток и переключатель изображений удалены. PreviewMode, TileColumns и CompactRows больше не входят в сохраняемую схему настроек; старые поля игнорируются и удаляются при первом запуске новой версии. Масштаб списка сохранён.
